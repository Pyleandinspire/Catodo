# 阶段五：筛选功能与AI集成开发

## 开发目标
1. 实现任务筛选功能（按分组、优先级、标签）
2. 实现自然语言解析
3. 集成 AI 辅助功能
4. 实现任务分解和超时情绪支持

## 具体任务

### 5.1 筛选功能实现
- 创建筛选面板组件
- 实现按分组筛选
- 实现按优先级筛选
- 实现按标签筛选

### 5.2 自然语言解析
- 创建 `lib/services/nlp_service.dart`
- 实现本地正则解析引擎
- 支持日期识别（今天、明天、后天、周几）
- 支持时间识别（几点几分）

### 5.3 AI 接口适配器
- 添加依赖：dio
- 创建 `lib/services/ai_service.dart`
- 实现通用 OpenAI 格式适配器
- 支持自定义 API Key、Base URL、Model Name

### 5.4 AI 功能实现
- 实现任务分解功能
- 实现任务调整建议
- 实现超时情绪支持对话
- 创建 AI 对话界面
