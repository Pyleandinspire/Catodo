# 07_UI美化与品牌资源集成开发

## 一、要实现的目标

### 1.1 核心目标
将应用从「功能可用」提升到「视觉精致、品牌统一」，让 Catodo 在所有平台都拥有一致且专业的视觉表现。

### 1.2 具体目标
1. **应用图标统一**：使用 `assets/Icon.png` 作为所有平台（iOS / Android / macOS / Windows / Web）的应用图标
2. **启动画面集成**：使用 `assets/splash.png` 作为应用启动时的开场画面
    - 启动画面与原生加载流程衔接，**不设置固定显示时间**
    - 应用加载完成（数据库初始化完成）后立即关闭启动画面
3. **整体视觉体系**：
    - 统一的色彩系统（主色、辅助色、语义色）
    - 统一的字体层级（标题、正文、辅助文本）
    - 统一的圆角、间距、阴影规范
    - 浅色 / 深色主题适配
4. **界面细节优化**：
    - 任务列表项视觉层次更清晰
    - 优先级、分组、标签使用统一的视觉语言
    - 空状态、加载状态、错误状态有友好的视觉表达
    - 按钮、输入框、卡片的交互反馈

## 二、具体要做什么

### Step 1：品牌资源准备与验证
1. 确认 `assets/Icon.png` 和 `assets/splash.png` 存在且尺寸合规
    - Icon 建议 1024×1024 PNG，透明背景
    - Splash 建议 1242×2436 或更高分辨率，与品牌色一致
2. 在 `pubspec.yaml` 的 `flutter.assets` 中注册资源目录
3. 修正 `notes_and_goal/Catodo.md` 中的图片引用路径（**已完成**）

### Step 2：应用图标集成（跨平台）
使用 `flutter_launcher_icons` 一次性生成所有平台的图标：

1. 在 `pubspec.yaml` 的 `dev_dependencies` 添加 `flutter_launcher_icons`
2. 添加配置块：
    ```yaml
    flutter_launcher_icons:
      android: true
      ios: true
      image_path: "assets/Icon.png"
      macos:
        generate: true
        image_path: "assets/Icon.png"
      windows:
        generate: true
        image_path: "assets/Icon.png"
        icon_size: 256
      web:
        generate: true
        image_path: "assets/Icon.png"
    ```
3. 执行 `dart run flutter_launcher_icons` 生成各平台图标
4. 验证各平台编译后的图标显示

### Step 3：启动画面集成（跨平台）
使用 `flutter_native_splash` 实现原生启动画面，加载完成自动关闭：

1. 在 `pubspec.yaml` 的 `dev_dependencies` 添加 `flutter_native_splash`
2. 添加配置块：
    ```yaml
    flutter_native_splash:
      color: "#FFFFFF"
      image: "assets/splash.png"
      android: true
      ios: true
      web: true
      android_12:
        image: "assets/splash.png"
        color: "#FFFFFF"
    ```
3. 执行 `dart run flutter_native_splash:create` 生成各平台启动画面
4. 在 `main.dart` 中保留启动画面到数据库初始化完成：
    ```dart
    void main() async {
      WidgetsBinding binding = WidgetsFlutterBinding.ensureInitialized();
      FlutterNativeSplash.preserve(widgetsBinding: binding);
      await NotificationService().initialize();
      runApp(const ProviderScope(child: CatodoApp()));
    }
    ```
5. 在 isarProvider 加载完成的 `data:` 分支中调用 `FlutterNativeSplash.remove()` 关闭启动画面

### Step 4：色彩系统与主题统一
1. 在 `lib/ui/theme/` 下新建 `app_colors.dart` 和 `app_theme.dart`
2. 定义品牌色彩体系：
    - 主色（Primary）：从 `Icon.png` 提取的品牌色
    - 辅助色（Secondary / Accent）
    - 语义色：成功 / 警告 / 错误 / 信息
    - 优先级专用色：高 / 中 / 低 / 无
    - 中性色：背景、卡片、分割线、文本（一级 / 二级 / 三级）
3. 构建 `ThemeData`：
    - 浅色主题 `lightTheme`
    - 深色主题 `darkTheme`
    - 在 `MaterialApp` 中应用 `theme` 和 `darkTheme`，跟随系统

### Step 5：字体与排版系统
1. 定义 `TextTheme`：
    - `displayLarge` / `displayMedium`：大标题
    - `titleLarge` / `titleMedium`：卡片标题、对话框标题
    - `bodyLarge` / `bodyMedium`：正文
    - `labelSmall`：标签、辅助说明
2. 全局统一字体（如使用 PingFang / 苹方 / 思源黑体回退）

### Step 6：组件视觉细节优化
1. **任务列表项 `TaskItem`**：
    - 优化勾选圆圈的视觉反馈（动画 + 颜色过渡）
    - 优先级标签改为左侧色条 + 右侧文字标签的组合
    - 标签 Chip 缩小尺寸，使用主题色淡化背景
2. **任务表单 `TaskFormScreen`**：
    - 卡片间距统一为 12 / 16
    - 输入框统一圆角与边框颜色
    - 按钮使用主题主色
3. **底部导航**：
    - 选中状态使用主题色 + 微动效（Scale 或 Indicator）
    - 未选中状态使用次级文本色，避免与背景混淆
4. **空状态**：
    - 列表为空时显示插画 + 引导文案 + CTA 按钮
5. **加载与错误状态**：
    - 统一的 Loading 占位（Shimmer 或 Skeleton）
    - 友好的错误提示（图标 + 标题 + 重试按钮）

### Step 7：交互动效
1. 路由切换：使用 Material 3 的 `pageTransitionsTheme`，统一为渐隐 + 滑入
2. 任务勾选完成：添加 200ms 的颜色过渡 + 划线动画
3. FAB / 关键按钮：长按或点击时的水波纹反馈
4. 列表插入 / 删除：使用 `AnimatedList` 或 `Flutter.flutter_staggered_animations`

### Step 8：跨平台适配细节
1. **macOS**：标题栏（TitleBar）颜色与主题同步，使用 `bitsdojo_window` 或原生配置
2. **Windows**：窗口边框、标题栏颜色适配
3. **iOS**：状态栏样式跟随主题（深浅）
4. **Android**：状态栏与导航栏颜色适配（`SystemChrome.setSystemUIOverlayStyle`）

### Step 9：可访问性与暗色模式
1. 暗色模式下重新校准对比度（WCAG AA 标准）
2. 关键交互元素最小可点击区域 ≥ 44×44
3. 颜色不作为唯一信息传递媒介（图标 + 文字双保险）

### Step 10：文档与归档
1. 在 `notes_and_goal/notes/` 下写入开发笔记，记录：
    - 资源生成命令与配置
    - 色彩 / 字体 / 间距规范表
    - 暗色模式适配清单
    - 跨平台已知差异与处理

## 五、风险与缓解

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 图标尺寸不足导致模糊 | 高分辨率设备显示锯齿 | 要求源图 ≥ 1024×1024 |
| 启动画面与 Flutter 接管衔接出现白屏 | 用户感知卡顿 | 使用 `FlutterNativeSplash.preserve` + `remove` 控制时序 |
| 深色主题颜色对比度不足 | 可访问性问题 | 使用 WCAG 检测工具校验 |
| 跨平台图标 / 启动画面差异 | 视觉不一致 | 在所有目标平台逐一验证 |
