# 阶段二：状态管理层开发

## 开发目标
1. 集成 Riverpod 状态管理
2. 实现核心 Provider 体系
3. 实现任务筛选功能
4. 实现艾森豪威尔矩阵视图数据派生

## 具体任务

### 2.1 Riverpod Provider 初始化
- 创建 `lib/providers/isar_provider.dart`
- 实现全局 Isar 单例 Provider

### 2.2 任务流 Provider
- 创建 `lib/providers/task_providers.dart`
- 实现 `activeTasksProvider`：监听未完成未删除任务流
- 实现任务的增删改操作 Notifier

### 2.3 筛选条件 Provider
- 创建 `lib/models/filter.dart`，定义 TaskFilter 类
- 实现 `filterConditionProvider`：维护筛选状态

### 2.4 派生视图 Provider
- 实现 `filteredTasksProvider`：根据筛选条件过滤任务
- 实现艾森豪威尔矩阵四个象限 Provider：
  - `urgentImportantTasksProvider`（重要且紧急）
  - `importantNotUrgentTasksProvider`（重要不紧急）
  - `urgentNotImportantTasksProvider`（紧急不重要）
  - `notUrgentNotImportantTasksProvider`（不重要不紧急）

### 2.5 按天聚合 Provider
- 实现 `tasksByDayProvider`：按日期分组任务
