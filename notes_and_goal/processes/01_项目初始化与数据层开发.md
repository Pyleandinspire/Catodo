# 阶段一：项目初始化与数据层开发

## 开发目标
1. 创建 Flutter 项目基础结构
2. 集成 Isar 数据库
3. 定义核心数据模型（Task 实体）
4. 实现数据持久化基础能力

## 具体任务

### 1.1 项目初始化
- 使用 Flutter CLI 创建新项目
- 配置 pubspec.yaml 添加依赖：isar, isar_flutter_libs, riverpod, flutter_riverpod, path_provider
- 配置 iOS/Android 平台权限

### 1.2 Isar 数据库配置
- 创建 Isar 数据库实例管理类
- 配置数据库 schema
- 实现数据库初始化与关闭逻辑

### 1.3 Task 实体定义
- 创建 `lib/models/task.dart` 文件
- 定义 Task 实体类，包含所有必要字段：
  - id（自增主键）
  - title（标题）
  - description（描述）
  - isCompleted（完成状态）
  - priority（优先级 0-3）
  - dueDate（截止日期）
  - tags（标签数组）
  - groupName（分组名称）
  - rrule（重复规则）
  - isRepeatParent（是否为循环任务母体）
  - createdAt（创建时间）
  - updatedAt（更新时间）
  - isDeleted（软删除标记）
  - reminderTimes（提醒时间）
- 添加必要的索引

### 1.4 数据访问层（DAO）
- 创建 `lib/data/task_dao.dart`
- 实现基础 CRUD 操作：
  - insertTask: 插入任务
  - updateTask: 更新任务
  - deleteTask: 软删除任务
  - getTaskById: 根据ID查询
  - getAllActiveTasks: 获取所有未删除任务
  - watchAllActiveTasks: 监听任务变更
