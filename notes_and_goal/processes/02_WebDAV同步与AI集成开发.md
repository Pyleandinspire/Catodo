# 阶段二：WebDAV 同步与 AI 集成开发

## 一、目标

实现跨平台数据同步和 AI 辅助功能，包括：

1. WebDAV 同步功能（增量同步、冲突解决）
2. .ics 文件导入导出
3. AI 任务分解功能
4. 任务超时情绪支持对话

## 二、具体任务

### 2.1 WebDAV 同步功能

**2.1.1 创建 WebDAV 服务**

- 创建 `lib/services/webdav_service.dart`
- 实现连接测试、文件上传下载、目录列表

**2.1.2 实现同步逻辑**

- 基于 `updatedAt` 时间戳的增量同步
- 冲突解决策略：服务端优先 + 本地修改标记
- 同步状态管理（同步中、已同步、同步失败）

**2.1.3 WebDAV 设置界面**

- 添加到设置页面，支持配置 URL、用户名、密码
- 测试连接功能

**2.1.4 WebDAV 配置持久化**

- 使用 `shared_preferences` 持久化保存 URL、用户名、密码
- 通过 `StateNotifierProvider` 在应用启动时自动加载已保存的配置
- 用户修改并保存后立即写入本地存储，重启后保持

### 2.2 .ics 导入导出

**2.2.1 创建日历服务**

- 创建 `lib/services/calendar_service.dart`
- 实现 .ics 文件解析和生成

**2.2.2 导入功能**

- 支持从文件选择器导入 .ics 文件
- 批量导入任务

**2.2.3 导出功能**

- 将任务导出为 .ics 格式
- 支持选择导出范围（全部、未完成、指定日期）

### 2.3 AI 任务分解

**2.3.1 完善 AI 服务**

- 实现任务分解 API 调用
- 添加错误处理和重试机制

**2.3.2 AI 设置界面**

- API Key、Base URL、Model Name 配置
- 测试连接功能

**2.3.3 AI 配置持久化**

- 使用 `shared_preferences` 持久化保存 `ai_provider_id`、`ai_api_key`、`ai_base_url`、`ai_model`
- 设置页面在 `initState` 阶段自动加载已保存的配置
- 修改并点击"保存配置"后立即写入本地存储
- 聊天页面共享该配置，确保所有 AI 调用使用同一份设置

**2.3.4 通用设置持久化规范**

- 所有设置项（包括 AI / WebDAV / 后续新增的用户偏好等）统一使用 `shared_preferences` 作为本地存储后端
- 命名约定：`<模块>_<字段>`，如 `webdav_url`、`ai_api_key`
- 涉及多字段的配置优先封装为 `StateNotifierProvider`，集中处理加载/保存逻辑

**2.3.3 任务分解界面**

- 选择任务后调用 AI 分解
- 展示分解结果，可选择添加子任务

### 2.4 情绪支持对话

**2.4.1 创建情绪支持服务**

- 实现超时任务情绪支持 API 调用

**2.4.2 超时任务检测**

- 定时检查超时任务
- 弹出情绪支持入口

**2.4.3 对话界面**

- 与大模型的聊天界面
- 支持发送消息和接收回复

## 三、测试标准

### 3.1 WebDAV 同步测试

| 测试项     | 测试步骤                                         | 预期结果                     |
| ---------- | ------------------------------------------------ | ---------------------------- |
| 连接测试   | 输入有效 WebDAV 地址、用户名、密码，点击测试连接 | 显示连接成功提示             |
| 连接失败   | 输入无效地址，点击测试连接                       | 显示连接失败提示             |
| 首次同步   | 清空服务器数据，执行同步                         | 本地任务上传到服务器         |
| 增量同步   | 修改本地任务，执行同步                           | 仅修改的任务上传             |
| 冲突解决   | 同时修改本地和服务器同一任务                     | 保留服务器版本，标记本地修改 |
| 配置持久化 | 保存 WebDAV 配置后重启应用                       | 配置自动加载，无需重新输入   |

### 3.2 .ics 导入导出测试

| 测试项         | 测试步骤                 | 预期结果                     |
| -------------- | ------------------------ | ---------------------------- |
| 导入 .ics      | 选择有效的 .ics 文件导入 | 任务成功导入，显示导入数量   |
| 导入无效文件   | 选择非 .ics 文件         | 显示错误提示                 |
| 导出全部任务   | 点击导出全部任务         | 生成包含所有任务的 .ics 文件 |
| 导出未完成任务 | 选择导出未完成任务       | 仅包含未完成任务的 .ics 文件 |

### 3.3 AI 任务分解测试

| 测试项     | 测试步骤                          | 预期结果             |
| ---------- | --------------------------------- | -------------------- |
| 配置验证   | 输入有效 API Key 和 URL，测试连接 | 显示连接成功         |
| 任务分解   | 选择一个复杂任务，点击分解        | 返回多个子任务建议   |
| 添加子任务 | 选择分解结果中的子任务，点击添加  | 子任务成功添加到列表 |
| API 失败   | 输入无效 API Key，尝试分解        | 显示错误提示         |

### 3.4 情绪支持测试

| 测试项       | 测试步骤                   | 预期结果               |
| ------------ | -------------------------- | ---------------------- |
| 超时检测     | 创建一个已过期的任务       | 任务显示超时标记       |
| 情绪支持入口 | 点击超时任务的情绪支持按钮 | 打开与 AI 的对话界面   |
| 对话功能     | 在对话界面发送消息         | 收到 AI 的情绪支持回复 |
