# 阶段三：UI层与核心功能开发

## 开发目标
1. 实现任务列表视图
2. 实现任务创建/编辑表单
3. 实现任务完成与删除功能
4. 实现基础导航结构

## 具体任务

### 3.1 导航结构
- 创建 `lib/main.dart`，配置 MaterialApp 和 Navigator
- 实现底部导航栏：待办列表、按天视图、艾森豪威尔矩阵、设置

### 3.2 任务列表视图
- 创建 `lib/ui/screens/task_list_screen.dart`
- 实现任务列表展示
- 实现任务项组件 `lib/ui/components/task_item.dart`

### 3.3 任务表单
- 创建 `lib/ui/screens/task_form_screen.dart`
- 实现任务创建/编辑表单
- 包含字段：标题、描述、截止日期、优先级、标签、分组、重复规则

### 3.4 任务操作功能
- 实现任务完成勾选功能
- 实现任务删除功能（软删除）
- 实现任务编辑跳转

### 3.5 按天聚合视图
- 创建 `lib/ui/screens/day_view_screen.dart`
- 按日期分组展示任务
- 支持日期切换

### 3.6 艾森豪威尔矩阵视图
- 创建 `lib/ui/screens/eisenhower_screen.dart`
- 四象限布局展示
- 支持拖拽调整优先级
