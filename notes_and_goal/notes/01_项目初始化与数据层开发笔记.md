# 阶段一开发笔记：项目初始化与数据层开发

## 一、项目架构概述

### 1.1 整体架构
采用经典的三层架构：
- **数据层**：Isar 数据库 + DAO 模式
- **状态管理层**：Riverpod
- **UI层**：Flutter Material Design

## 二、关键技术实现

### 2.1 Isar 数据库配置
- 使用 Isar 3.x 版本，支持强类型对象存储
- 通过 `@collection` 注解定义实体
- 使用 `@Index` 注解优化查询性能
- 支持异步流监听（`watch()`）实现实时数据同步

### 2.2 Task 实体设计要点
- `id`：自增主键，Isar.autoIncrement
- `isDeleted`：软删除标记，用于 WebDAV 同步
- `updatedAt`：更新时间戳，用于冲突合并
- `rrule`：重复规则字符串（RFC 5545）
- `reminderTimes`：支持多个提醒时间点

### 2.3 状态管理设计
- `isarProvider`：全局单例，提供 Isar 实例
- `activeTasksProvider`：StreamProvider，监听活跃任务
- `filterConditionProvider`：StateProvider，维护筛选状态
- `filteredTasksProvider`：派生 Provider，根据筛选条件过滤

### 2.4 筛选机制实现
支持三种筛选维度的组合：
- 按分组筛选
- 按优先级筛选（0-3）
- 按标签筛选

## 三、遇到的问题与解决方案

### 3.1 Isar QueryBuilder API 变更
**问题**：`isDeletedEqualTo()` 方法不存在于 `QueryBuilder` 上

**解决方案**：需要先调用 `.filter()` 方法，再调用条件方法

```dart
// 错误方式
isar.tasks.where().isDeletedEqualTo(false)

// 正确方式
isar.tasks.filter().isDeletedEqualTo(false)
```

### 3.2 通知服务跨平台配置
**问题**：macOS 平台缺少初始化配置导致崩溃

**解决方案**：在 `InitializationSettings` 中添加 `macOS` 参数

```dart
const InitializationSettings settings = InitializationSettings(
  android: androidSettings,
  iOS: iosSettings,
  macOS: macosSettings,  // 必须添加
);
```

### 3.3 rrule 库 API 兼容性
**问题**：新版本 `RecurrenceRule` 没有 `getDates()` 方法

**解决方案**：使用正则解析 RFC 5545 规则字符串，实现简单的重复逻辑

### 3.4 构造函数参数类型匹配
**问题**：Isar 要求构造函数参数类型必须与属性类型完全匹配

**解决方案**：使用 `List<String> tags = const []` 替代 `List<String>? tags`

### 3.5 macOS 运行黑屏问题
**问题**：应用在 macOS 上运行时显示黑屏

**原因分析**：
- isarProvider 是 FutureProvider，数据库初始化是异步操作
- UI 在等待 Future 完成时没有显示任何内容
- MaterialApp 的 home 直接使用 Scaffold，没有处理异步状态

**解决方案**：
使用 `Consumer` 包裹主界面，监听 `isarProvider` 的状态：

```dart
home: Consumer(
  builder: (context, ref, child) {
    final isarAsync = ref.watch(isarProvider);
    return isarAsync.when(
      data: (_) => Scaffold(...),  // 数据库就绪后显示主界面
      loading: () => Scaffold(      // 加载中显示进度条
        body: Center(
          child: CircularProgressIndicator(),
        ),
      ),
      error: (error, stack) => Scaffold(  // 错误处理
        body: Center(child: Text('初始化失败: $error')),
      ),
    );
  },
),
```

**验证结果**：修复成功，应用能正常显示加载状态并进入主界面

## 四、性能优化策略

### 8.4 动态分组筛选
**实现要点**：
- 新增 `allGroupsProvider` 自动收集所有任务的分组名称
- 筛选对话框动态生成分组选项，包括预设分组和自定义分组
- 避免重复显示预设分组

**技术细节**：
```dart
final allGroupsProvider = Provider<List<String>>((ref) {
  final asyncTasks = ref.watch(activeTasksProvider);
  
  return asyncTasks.when(
    data: (tasks) {
      final groups = <String>{};
      for (final task in tasks) {
        if (task.groupName != null) {
          groups.add(task.groupName!);
        }
      }
      return groups.toList()..sort();
    },
    loading: () => [],
    error: (_, __) => [],
  );
});
```

### 8.5 按天视图排序逻辑优化
**实现要点**：
- 使用 `DateTime(9999)` 作为无日期任务的 key，确保排序在最后
- 超时任务按日期倒序排列（最新超时的在前）
- 今天及未来任务按日期正序排列

**技术细节**：
```dart
final sortedDates = groupedTasks.keys.toList()
  ..sort((a, b) {
    if (a.year == 9999) return 1;
    if (b.year == 9999) return -1;
    
    final aIsOverdue = a.isBefore(today);
    final bIsOverdue = b.isBefore(today);
    
    if (aIsOverdue && !bIsOverdue) return -1;
    if (!aIsOverdue && bIsOverdue) return 1;
    
    if (aIsOverdue && bIsOverdue) {
      return b.compareTo(a);
    }
    
    return a.compareTo(b);
  });
```
