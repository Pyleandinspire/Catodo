# 应用图标替换笔记

## 写作日期

2026-06-06

## 一、开发概述

为 Catodo 替换默认的 Flutter 应用图标，使用自定义设计的猫+时钟图标。目标是同时生成 Android、iOS、Windows、macOS、Web 全平台的图标文件。

## 二、工具选择

### 使用 flutter_launcher_icons

这是 Flutter 社区标准的图标生成工具，一条命令自动生成所有平台的图标文件。

**优势**：
- 一键生成多平台图标
- 自动处理不同平台的尺寸要求
- 支持 Android adaptive icon 配置
- 社区维护活跃

**依赖**（开发依赖，不需要保留在最终项目中）：
```yaml
dev_dependencies:
  flutter_launcher_icons: ^0.14.3
```

## 三、图标源文件

项目中共测试了三个图标文件：

| 文件 | 尺寸 | 说明 | 使用情况 |
|------|------|------|----------|
| `app_Icon.png` | ~512x512 | 蓝色圆角背景+白色图标 | 首次使用，图标偏小 |
| `app_Icon-HD.png` | 1024x1024 | 深蓝背景+白色猫+时钟 | 第二次使用，图标偏小 |
| `icon.png` | 更大 | 无背景纯图标线稿 | 最终采用 |

## 四、遇到的问题及解决方案

### 问题一：Android Adaptive Icon 裁切

**现象**：Android 上图标显示非常小，被周围深蓝色背景包围。

**原因**：Adaptive Icon 的安全区域只有中间 66%，如果图标本身有圆角背景，整体会被裁切得很小。

**解决**：
1. 使用纯线稿图标（无背景色）
2. 背景色通过 `adaptive_icon_background` 配置
3. 图标主体尽量占满画布，四周留白控制在 10% 以内

**配置示例**：
```yaml
flutter_launcher_icons:
  android: true
  ios: true
  windows:
    generate: true
    image_path: "assets/icon.png"
  macos:
    generate: true
    image_path: "assets/icon.png"
  web:
    generate: true
    image_path: "assets/icon.png"
  image_path: "assets/icon.png"
  adaptive_icon_background: "#1A2A3A"
  adaptive_icon_foreground: "assets/icon.png"
```

### 问题二：iOS App Store 透明通道警告

**现象**：生成 iOS 图标时提示 `WARNING: Icons with alpha channel are not allowed in the Apple App Store`。

**原因**：PNG 图片包含透明度通道，App Store 不接受。

**说明**：对于开发版和内部测试版本，这个警告可以忽略。如果要发布到 App Store，需要使用无透明背景的图片。

### 问题三：PowerShell 不支持 && 语法

**现象**：执行 `flutter pub get && dart run flutter_launcher_icons` 报错。

**原因**：PowerShell 5 不支持 Bash 的 `&&` 链式命令。

**解决**：分开执行两条命令
```powershell
flutter pub get
dart run flutter_launcher_icons
```

## 五、操作步骤

### 5.1 添加依赖和配置

在 `pubspec.yaml` 的 `dev_dependencies` 中添加：
```yaml
flutter_launcher_icons: ^0.14.3
```

在 `pubspec.yaml` 的 `flutter:` 节点下添加配置：
```yaml
flutter_launcher_icons:
  android: true
  ios: true
  windows:
    generate: true
    image_path: "assets/icon.png"
  macos:
    generate: true
    image_path: "assets/icon.png"
  web:
    generate: true
    image_path: "assets/icon.png"
  image_path: "assets/icon.png"
  adaptive_icon_background: "#1A2A3A"
  adaptive_icon_foreground: "assets/icon.png"
```

### 5.2 执行生成

```powershell
flutter pub get
dart run flutter_launcher_icons
```

### 5.3 验证生成结果

检查以下位置：
- **Android**：`android/app/src/main/res/mipmap-*/ic_launcher.png`
- **iOS**：`ios/Runner/Assets.xcassets/AppIcon.appiconset/`
- **Windows**：`windows/runner/resources/app_icon.ico`
- **macOS**：`macos/Runner/Assets.xcassets/AppIcon.appiconset/`
- **Web**：`web/icons/` + `web/favicon.png`

### 5.4 清理

生成完成后，从 `pubspec.yaml` 中移除 `flutter_launcher_icons` 依赖和配置。

## 七、图标设计建议

### 源图标要求

- **格式**：PNG（推荐带透明背景）
- **最小尺寸**：1024x1024 像素
- **图标主体**：占满画布，四周留白 < 10%
- **背景**：透明或纯色均可（背景色通过配置指定）

### Android Adaptive Icon 最佳实践

1. 使用透明背景的图标
2. 图标线稿居中，占满安全区域
3. 背景色与图标形成良好对比
4. 避免在安全区域边缘放置重要内容

## 九、开发心得

1. **图标尺寸宁大勿小**：源图标越大，生成的小尺寸图标越清晰
2. **透明背景优于实色背景**：透明背景配合配置的背景色，适应性更强
3. **图标主体占满画布**：避免四周留白太多，导致在 Android adaptive icon 上显示过小
4. **清理临时依赖**：flutter_launcher_icons 是开发工具，不需要保留在最终项目中
