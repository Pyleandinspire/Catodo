# 功能要求

1. 任务创建、编辑、完成、删除
2. 截止日期与提醒通知
3. 任务循环次数
4. 重复任务提示
5. 任务状态管理：要保证能够在有大量的任务的情况下，还能够快速地刷新，管理任务状态
6. 代办列表视图
7. 按天聚合/视图
8. 数据持久化（本地存储）
9. 列表/项目分组、优先级、标签
10. 筛选查看任务（按分组，优先级，标签三种）
11. Eisenhower Matrix视图
12. 导入导出（.ics）
13. webdav跨平台同步
14. 按天视图UI改善和查看模式
15. 左上角显示按天视图和任务数，缩小尺寸
16. 右上角新增"查看模式"按钮，支持两种模式：（这个模式也是持久化设计，一次设置始终生效）
    - "专注今日"：只显示今天的任务
    - "隐藏过期"：显示除了overdue的任务
17. 导入导出功能优化（新增完整格式导入导出和同步），webdav也使用这个进行同步
18. WebDAV同步模式选择，让用户可以选择同步模式

19. 自然语言解析
20. AI辅助调整任务，任务分解
21. 和大模型交谈确定任务进度，要不要调整
22. 在任务超时后可以选择和大模型交流，要提供情绪支持和改进建议
23. 多模型API支持：支持 OpenAI 及国产大模型（DeepSeek、豆包、GLM、千问、Kimi 等），提供预设配置一键切换，支持自定义 OpenAI 兼容端点
24. 设置项持久化：所有应用设置（AI API 配置、WebDAV 配置、用户偏好等）需在本地持久化保存，应用重启后自动恢复
